## Мета
Поглибити та закріпити знання HTML, CSS і JavaScript; набути практичних навичок створення вебзастосунків.

## Реалізовано
- Додавання справ через `prompt()`.
- Відображення списку з `renderTodo()` (шаблонні рядки) та `render()` (`map()`, `innerHTML`).
- Лічильники всіх і невиконаних справ (`filter()`).
- Позначення виконання та видалення.
- Збереження й відновлення справ через `localStorage`.
- Порожній стан, перевірка введення, адаптивне оформлення.

## Запуск
Відкрити `index.html` у браузері. Для перевірки збереження краще запускати через локальний сервер або опубліковану HTTPS-сторінку.

## Публікація на GitHub Pages
1. Створити публічний репозиторій на GitHub, наприклад `todo-list-lab`.
2. Завантажити `index.html`, `script.js`, `README.md` у корінь репозиторію.
3. Відкрити **Settings → Pages → Build and deployment → Deploy from a branch**, обрати `main` та `/ (root)`, зберегти.
4. Дочекатися публікації та перевірити сторінку, додавання, позначення, видалення і відновлення після перезавантаження.
5. Вставити справжні посилання в звіт та Moodle.

## Перевірки
1. Початковий стан: 0 / 0.
2. Додати A: 1 / 1; додати B: 2 / 2.
3. Відмітити A: 2 / 1; зняти відмітку: 2 / 2.
4. Видалити B: 1 / 1; видалити A: 0 / 0.
5. Спробувати порожній рядок і скасування `prompt()` — список не змінюється.
6. Додати справу, перезавантажити сторінку — справа зберігається.
7. Додати `<script>alert(1)</script>` як назву — текст відображається без виконання скрипта.
